# CASEFIRE

CASEFIRE — небольшой 3D-шутер от первого лица, написанный на C++17 с нуля без готового игрового движка. Проект использует OpenGL 3.3, GLFW, встроенный минимальный загрузчик glad, GLM, nlohmann/json и OpenAL.

## Возможности

- Минималистичная 3D-арена: плоский пол и несколько кубов-стен для укрытий.
- Управление от первого лица: `WASD` для движения, мышь для поворота камеры, левая кнопка мыши для стрельбы.
- Красные враги-кубы имеют 3 HP, идут к игроку и наносят 10 урона при касании.
- У игрока 100 HP; при смерти включается состояние «Игра окончена», перезапуск — клавишей `R`.
- За каждого убитого врага игрок получает 10 монет.
- Главное меню и магазин:
  - `ENTER` — начать игру.
  - `S` — открыть магазин из главного меню.
  - `O` — открыть кейс за текущую цену кейса.
  - `E` — выбрать следующий скин из инвентаря.
  - `X` — продать выбранный нестандартный скин за 50% его цены.
  - `B` — вернуться в главное меню.
- Сохранение данных в JSON:
  - `profile.json` — монеты, здоровье, флаг бана и выбранный скин.
  - `inventory.json` — список ID полученных скинов.
  - `skins.json` — ID, название, RGB-цвет, цена и шанс выпадения каждого скина.
  - `case_config.json` — цена кейса.
  - `admin.json` — флаг доступа к админ-панели.
- Админ-панель по `F1`, доступная только если в `admin.json` указано `"admin": true`:
  - начислить монеты;
  - выдать скин по ID;
  - изменить цену кейса;
  - изменить шансы выпадения скинов;
  - забанить или разбанить игрока.

## Зависимости для Arch/CachyOS

```bash
sudo pacman -S --needed base-devel cmake mesa glfw-x11 glm nlohmann-json openal
```

Пакет `glad` отдельно больше не нужен: в проект добавлен минимальный встроенный загрузчик glad, поэтому CMake больше не падает с ошибкой `glad was not found`. Если у вас используется Wayland-версия GLFW, замените `glfw-x11` на пакет GLFW, который принят в вашей системе.

## Сборка и запуск

```bash
cmake -S . -B build
cmake --build build -j$(nproc)
./build/casefire
```

Игра читает и записывает JSON-файлы в текущую рабочую директорию. Чтобы файлы профиля и конфигурации лежали рядом с этим README, запускайте игру из корня репозитория.

## Управление

| Режим | Клавиша / мышь | Действие |
| --- | --- | --- |
| Главное меню | `ENTER` | Начать матч |
| Главное меню | `S` | Открыть магазин |
| Любой режим | `F1` | Открыть админ-панель, если в `admin.json` указано `admin: true` |
| Любой режим | `ESC` | Выйти |
| Игра | `WASD` | Движение |
| Игра | Мышь | Поворот камеры |
| Игра | Левая кнопка мыши | Выстрел |
| Игра окончена | `R` | Перезапустить матч |
| Магазин | `O` | Открыть кейс |
| Магазин | `E` | Выбрать следующий скин |
| Магазин | `X` | Продать выбранный нестандартный скин |
| Магазин | `B` | Назад в главное меню |

## Примечания

- Текущие HP, монеты, количество врагов, состояние магазина, бан и экран «Игра окончена» отображаются в заголовке окна. Так проект остаётся простым и не требует библиотеки шрифтов.
- Звуки генерируются во время запуска через OpenAL: выстрел, попадание, открытие кейса и ошибка.
- Шансы выпадения скинов считаются процентами. Для предсказуемого выпадения поддерживайте сумму шансов равной 100 через админ-панель.
